# Go API client

This is the Open Api Spec 3 for the Harness APIs. This is under active development. Beware of the breaking change with respect to the generated code stub

## Overview
This API client was generated by the [swagger-codegen](https://github.com/swagger-api/swagger-codegen) project.  By using the [swagger-spec](https://github.com/swagger-api/swagger-spec) from a remote server, you can easily generate an API client. This client used specification present [here](https://github.com/harness/harness-openapi/blob/master/merged/spec-first.json)

- API version: 1.0
- Package version: 1.0.0
- Build package: io.swagger.codegen.v3.generators.go.GoClientCodegen

The `nextgen` package is generated from `nextgen/api/swagger.yaml` with the same generator, swagger-codegen `3.0.33`.

## Generate the client

Update the OpenAPI spec, then regenerate. The Go files under `nextgen/` come from that run.

```bash
npm run generate
```

That runs `node scripts/generate.mjs`. It asks which client to generate. Choose `nextgen` to regenerate this package from `nextgen/api/swagger.yaml`.

Generate one client without the prompt:

```bash
npm run generate -- nextgen
```

Use a different spec file:

```bash
node scripts/generate.mjs nextgen --spec path/to/spec.yaml
```

The script runs `swaggerapi/swagger-codegen-cli:3.0.33` through Docker. If Docker is not installed, it uses `swagger-codegen` on your PATH. Node.js is required for the script. No npm packages are installed.

`nextgen/version_json_test.go` is listed in `nextgen/.swagger-codegen-ignore`, so regeneration leaves that test in place.

After generating, check the package:

```bash
go test ./nextgen/ -count=1
```

## Steps to run GO client
Updated main.go by replacing <account> with Harness account value and <x-api-key-value> with x-api-key generated for same account. Also call any function (i.e swaggerCodeGenGetOrgs(), swaggerCodeGenGetAccountScopedSecret(), swaggerCodeGenGetAccountScopedSecrets() ) in main function and run
```
go mod tidy
```
```
go build . 
```
```
go run main.go
```
